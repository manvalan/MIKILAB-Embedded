# MIKILAB Embedded

Research and prototyping platform for Linux-capable embedded hardware, custom carrier boards, System-in-Package architectures, power management, high-speed interfaces, and embedded system design.

## Current Focus

Initial research is focused on the Octavo Systems OSD32MP15x SiP based on the STM32MP1 family.

The repository is used to collect:

- architecture studies
- datasheet and application-note analysis
- schematic design
- power-tree design
- pin and peripheral mapping
- PCB layout studies
- KiCad design files
- experiments and prototypes
- design notes and decisions

## Status

Early research and architecture phase.
